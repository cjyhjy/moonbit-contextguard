保持独立证据验证、未知格式/篡改/采集不完整回退、可信进程字段、SHA 回查和完整说明开销。默认对照保留 OpenCode 原生截断/压缩；如采用进程包装接入，应另列同包装器关闭压缩的对照，不能混淆采集变化和压缩收益。

预计修改集中在 `adapters/`、`evaluation/`、相关测试与文档。核心 parser 暂不扩展。正式模型实验、提交、推送和发布分别记录，不能用本地通过代替这些状态。

## 本轮报告入口

- `reports/integration-local.json`：真实 OpenCode + 本地脚本化协议服务，包含全部 14 个会话；源码指纹与最终验收对应。
- `reports/integration-ledger.synthetic.jsonl` / `.json`：五个配对任务的合成用量账本，不是实际账单。
- `reports/verification.json`：源码检查、35 项 MoonBit 测试在三个后端、Node 回归、14 项账本测试、独立审计、包消费；同时校验运行时验收记录与源码对应。
- `reports/package-verification.json`：开发版便携 ZIP 的冻结快照、解包复验及哈希；需要核对版本为 0.3.0-dev.1。
- `reports/integration-delivery.md`：最终完成项、未完成项及提交/推送/发布状态。
- `reports/online-pilot.json`、`reports/online-pilot-analysis.json`：真实模型原始结果摘要与本地证据复核。
- `reports/online-pilot-result.txt`：五对先导结果、费用口径、剩余问题；本阶段状态以此为准。
