# 开发与 AI 协作事实

2026-10-22，本项目在用户授权的本地工作范围内，由 Codex 的 GPT-6-astra / ultra 主代理和三个同配置子代理协作实现、调试、调研、编写技术文档与离线验收。主代理负责 MoonBit 核心、进程包装、集成和交付；并行任务分别负责固定版本近邻、独立夹具/账本、适配/演示。

未把 AI 代理写成人类团队成员，也没有代填用户身份、贡献声明或诚信承诺。此文件是协作记录，不是参赛者本人声明。用户仍需亲自理解代码与实际边界。

实现为本次本地新增。HarnessPro hook、RTK/Headroom/Opencode 参考文件及 MoonBit 运行时的具体来源和许可见 `THIRD_PARTY_NOTICES.md` 与锁文件。相邻 URI Template 项目仅用于读取已有工具链和构建经验；未复制其业务算法、未计作本次新成果、未修改其目录。

开发过程保留在本地源码、测试、开发日志和报告。项目执行聊天未操作共享 Git；总控已按用户授权记录真实开发阶段的本地提交，没有凑数或伪造历史。其九条真实历史现已按 `HISTORY.md` 提取到独立公开仓库，随后追加独立发布与 CI 配置修复提交；没有重写、squash 或伪造开发历史。Mooncakes/npm 发布与正式参赛提交未执行，CI 结论以对应 SHA 的 Actions run 为准。

赛事规则由组合总控另行核实；独立仓库不依赖上级文件，也不提供赛事资格结论。此包仅提供技术事实和证据，不包含冒充本人撰写的正式申报书。
