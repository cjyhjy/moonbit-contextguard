# 本地交互演示

演示直接调用 MoonBit 编译产物，不使用模型 API、不执行来自浏览器的 shell 命令、不需要 npm 依赖。

```sh
node tools/build.mjs
node demo/server.mjs
```

在浏览器打开 [本地演示](http://127.0.0.1:4187)。默认仅绑定 `127.0.0.1:4187`；如端口被其他项目占用，可用 `CONTEXTGUARD_DEMO_PORT=4188 node demo/server.mjs`。服务不会开放到局域网，不提供远程部署。

## 推荐演示顺序

1. 默认加载“测试日志 · 关键失败藏在中间”。原文来自合成测试程序的真实 Node 进程，包含 75 个测试和一个中段失败。页面显示核心给出的证据投影、长度、必要证据和进程上下文。
2. 点击“生成头尾截断反例”，观察缺失证据被补回。候选与原文分别传入校验器；不是由压缩器自己宣布成功。
3. 在“原始证据”选择 `failure`，回查对应原始行与实际断言。回查使用最近一次校验的原文快照；编辑输入后会标为待重新校验。
4. 把预算改为 `100` 再校验，观察原文回退。预算不足时不会删掉必要证据来追求数字。
5. 切换到 rg JSON 的长 Unicode 命中，查看完整命中行与上下文。零匹配和路径错误分别保留退出码；stderr 在页面底部单独展示。
6. “运行四组对照”分别提交原文候选、头尾截断、自定义候选和自动抽取候选，显示候选长度、候选缺失证据、最终决策与交付长度。

“使用外部候选”关闭时，核心生成抽取式候选；开启后校验文本框中的实际文本，空字符串同样是候选。输出格式、预算、退出码、范围和上游截断状态均可编辑，用来测试失败路径。这些值在真实进程包装器中来自进程；在交互实验中来自用户表单。

## 计量与范围

- 长度统一是 UTF-16 code units，字符减少不等于模型 token、真实费用或任务成功率。
- `evidence_projection` 是证据投影，不保证完整 TAP/rg 流语法；它省略允许省略的源单元，并保留可回查行号。
- 演示使用 fixture 的 stdout 作为原文。单独捕获的 stderr 始终另行展示，不计入页面字符减少。不会把 stderr 的保存声称为核心投影完成的工作。
- 四组对照复用同一独立验证器；交付长度是修复或回退后的结果，不能当作未校验候选的保留率。正式外部字段覆盖评测见项目 `reports/evaluation.md`。
- 夹具源程序与语料是合成的，但输出来自真实本地子进程。没有生产追踪、模型调用或在线降本实验。

## 服务和验收

`demo/server.mjs` 提供静态资源、`/fixtures/`、只读健康信息以及 `POST /api/guard`。守卫函数从 `tools/api.mjs` 导入并同步执行；服务拒绝跨源请求、非 JSON API 请求、隐藏/越界文件访问，正文上限为 2 MiB。未提供任意文件读取或命令执行 API。

```sh
node --test tests/demo-server.test.mjs
```

HTTP 测试需要允许回环端口监听；在禁止本地端口的沙箱中会出现 `EPERM`，应在用户允许的本地测试环境运行，而不是略过并宣称通过。测试覆盖真实核心压缩、修复、预算/未知格式回退及静态清单路径。

2026-10-22 已使用 Tabbit 浏览器完成桌面与 390 像素移动视口检查，验证候选修复、预算回退、证据行回查、四组对照、Unicode 命中、未知格式及上游截断。移动视口无页面级横向溢出。截图保存在 `reports/demo-desktop.png`、`reports/demo-mobile.png`，详细记录见 `reports/demo-browser.json`。这是本地 UI 验收，不是外部用户试验。
