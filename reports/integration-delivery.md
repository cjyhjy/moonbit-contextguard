## 已完成

1. 固定 OpenCode 1.19.5 官方源码和归档 SHA-256，在项目缓存使用已校验的 CLI。项目插件入口改为自动发现支持的 `.js`，保留内部 `.mjs` 模块。全局安装未替换。
2. 补齐调用开始、hook 决策、原生完成/错误、重试和回查事件；跳过、fallback、异常均有原因；run/session/call 关联，跨实验的 pair/run ID 唯一。保留核心独立校验、严格允许列表、可信退出码、截断回退和完整正文开销。
3. 压缩结果提供可直接调用的回查命令和原始行数；回查验证 receipt 和原文 SHA，并记录调用结果。日志写入失败时保留原输出。

5. 请求级 usage 导入能够去重、校验完整请求清单、区分缓存输入、检查响应模型，并区分实付/估算/合成费用。原始 usage 缺失时拒绝记零。OpenCode step_finish 明确只作为部分用量证据。

|---|---|

| Node 回归 | 98/98 通过；另有账本测试 14/14 通过 |
| MoonBit | JS、native、wasm-gc 各 35/35 通过；格式、check/build/test 均通过 |
| 独立审计与消费者 | 核心/嵌套证据删除审计通过；从实际源码 ZIP 解包的独立消费项目在三个后端通过各 8 项 API 测试与示例 |
| 记录与源码一致性 | `verification.json` 检查编译产物及本地运行时收据的源码指纹；不会将旧记录用于修改后的接入实现 |
| 便携包 | `../release/contextguard-0.3.0-dev.1.zip` 与 `.sha256`；冻结快照、解包复验和最终哈希见 `package-verification.json`，需核对版本和 passed 状态 |

实际本地平台为 macOS arm64，Node 26.7.0。没有在 Linux/Windows 上运行本轮 OpenCode 接入验收。

五个实验组任务中，平面 TAP 和嵌套 TAP 两个任务发生实际压缩，各成功回查一次；rg 任务的两个搜索输出因为必要证据超预算回退；不支持命令和短输出对照均保留原文。全部五个任务都留在报告中，没有删除未触发样本。44 条请求用量记录覆盖配对任务的主调用及辅助请求，全部标注 synthetic。

**这些会话使用确定性协议响应、预设修复步骤和虚构用量。** 它们证明本地接入和采集链路，不证明模型自主修复、真实项目任务成功率或费用收益。`integration-ledger.synthetic.jsonl` / `.json` 不是实际账单。
